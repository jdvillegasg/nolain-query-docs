    What queries cost

    nolainquery.com does not charge you for using the desktop app or the Cloud API. There is no nolainquery subscription fee and no credit balance to spend.

    The money you spend is OpenRouter’s bill for language-model calls. The desktop sends your OpenRouter key with each request. OpenRouter bills those calls to your OpenRouter account. Running the generated code against your file on the local engine does not itself create an OpenRouter charge.

    A single question is often several model calls: intent classification, optional clarification, code generation, and sometimes repair. Schema-only answers (for example, “What columns do I have?”) can skip generation, but most conversation turns still call a model at least once.

    How we measured this

    We ran 50 hard questions through the desktop conversation loop against one local file containing sales information.

    These are some examples of the queries made:

    • What is the month-over-month revenue growth rate for United Kingdom in 2010?
    • Which products account for the top 80% of revenue?
    • Calculate the customer churn rate between 2009 and 2010.
    • Gini coefficient of revenue distribution in 2010.

    The queries involved descriptive analyses that need multi-step Pandas work: growth rates, rolling windows, concentration, churn, percentiles, and similar.

    Each run used the hosted generation path (start → message → local execute → optional repair), Pandas as the engine, and retries enabled. Visualization was off. When the product asked for a clarification, the harness automatically picked the first offered interpretation for every term and resent the question.

    Token totals below are worker totals from those runs (generation and repair). Conversation-side calls — classification, semantic reading, optional answer framing — are not included. A live question can therefore cost a little more than the figures here.

    USD figures use the catalog OpenRouter rates recorded for those models (input / output per million tokens):

    • GPT-5.6 Luna $0.20 / $1.20
    • DeepSeek V4 Flash 0731 $0.14 / $0.28

    They are estimates of what OpenRouter would bill for the measured tokens, not a price guarantee.

    Average cost per query

    Two Pandas-only runs (no computation graph):

    Model Code success Mean tokens (in / out) Estimated OpenRouter cost per query
    GPT-5.6 Luna 49 / 50 (98%) 1,652 / 945 ~$0.0015
    DeepSeek V4 Flash 0731 35 / 50 (70%) 2,281 / 441 ~$0.0004

    Read those averages as: on this hard retail slice, a typical Pandas-only question was well under a cent. DeepSeek was cheaper per question but succeeded less often and needed 23 Pandas retries (21 sandbox, 2 runtime). Luna needed none.

    Enabling Computation graph on the same Luna setup raised cost sharply: about ~$0.017 per query on average (roughly 10× the Pandas-only Luna run), with 87 compiler retries across 50 questions. Leave the graph off unless you need that artifact.

    For your own recent activity, Settings → Query usage shows local token counts. That is usage evidence on this device, not OpenRouter’s invoice.
