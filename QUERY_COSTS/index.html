    Query LLM costs

    End-to-end token and cost estimates per query. Capability: data_analysis. Plan: data_analysis/pandas. Tables are generated by scripts/compute_query_costs.py — do not edit token/cost cells by hand.

    Architecture: SYSTEM_ARCHITECUTRE.md · Conversation flow: CONVERSATION_WORKFLOW.md

    Column conventions

    Col Meaning
    ot Output tokens
    ict Input tokens (cache hit)
    imt Input tokens (cache miss)
    co Output token cost (ot × price_out)
    cic Input cache cost (ict × price_in_hit)
    cim Input miss cost (imt × price_in_miss)
    ct Total scenario cost (co + cic + cim)

    All costs in USD. Token counts for GPT-5.6 Luna are scaled to 60% of DeepSeek counts before pricing.
