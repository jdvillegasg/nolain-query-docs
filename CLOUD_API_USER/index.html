    Nolain Data Query — Getting Started (Users)

    Welcome! This guide explains how to get your API key and start querying your data with the Nolain desktop app.

    Step 1 — Create an Account on the Nolain Portal

    1. Go to nolain.app (the portal).
    2. Click Sign Up and create your account with your email address.
    3. Verify your email.

    Step 2 — Generate Your API Key

    1. Log in to the portal.
    2. Navigate to Dashboard → API Keys.
    3. Click Generate New Key.
    4. Copy the key — it will only be shown once. Store it in a safe place (e.g. a password manager).

    Your key looks like this:

    sk-free-3f9a1c72b4de5e01

    Keep your key private. Anyone with your key can spend your credits.

    Step 3 — Enter Your API Key in the Desktop App

    1. Open the Nolain Data Query desktop app.
    2. In the sidebar, click ⚙️ Settings.
    3. Paste your API key into the API Key field.
    4. Click Save. The app will validate your key and show your plan and usage.

    Your key is stored locally on your machine — it is never sent anywhere except to the Nolain API server when you make a query.

    Step 4 — Start Querying

    1. Click Local Parquet in the sidebar to select a data file (.parquet or .csv).
    2. Type a natural language question in the query bar, e.g.:

    What is the total revenue by country?

    1. Press Enter or click Execute.
    2. Results appear instantly in the table below.

    When your credit balance reaches zero, you'll see a message like:

    "No credits remaining on your account. Subscribe or top up at the portal to continue using the Cloud API."

    To add credits, visit Account → Subscription or Top Up on the portal.

    Frequently Asked Questions

    Can I have multiple API keys? Yes — you can generate multiple keys from the portal. They all spend the same account credit balance.

    What happens if I lose my key? Go to the portal, deactivate the old key, and generate a new one. Paste the new key into the desktop app settings.

    Is my data sent to the cloud? Only the column names and your natural language query are sent to the cloud to generate the computation plan. Your actual data files never leave your machine.
