    Credits and model-call charges

    After a first query, the practical question is how much another query may use. Nolain charges credits for language-model calls in the Cloud API. Running the returned code against your file on the local engine does not itself consume credits.

    How one model call is charged

    The current billing configuration converts model cost into token credits at 1,000 credits per US dollar, rounding up. It then adds surplus credits, a configured service margin. The current surplus rate is 100%.

    token_credits   = ceil(model_cost_usd × 1000)
surplus_credits = ceil(token_credits × 1.0)
charged_credits = token_credits + surplus_credits

    For example, a model call costing $0.0026 produces 3 token credits after rounding. The current surplus adds 3 more, so the account is charged 6 credits. This example explains the formula; it is not a fixed per-call price.

    The implementation records a charge after each completed model call. A single question may invoke several calls for intent classification, ambiguity analysis, code generation, graph compilation, visualization formatting, repair, or optional answer framing. Calls completed before a failure or cancellation remain chargeable. Polling the status of work already started does not create a model charge.

    Which requests can avoid a charge

    A response that never invokes a model does not create a model-call charge. Some schema-only answers, such as a locally available column list or row count, can take that path. Most conversation turns use at least the intent classifier, including turns eventually judged off-topic or out of scope.

    Clarification is not a flat charge of its own. The model calls used to detect ambiguity are charged, and the clarified request may trigger further calls.

    What the plan numbers currently mean

    The repository declares monthly plan constants of 1,000 credits for free and 50,000 credits for premium. The website displays those amounts as UTC-month plan allowances.

    However, the current repository contains no automated monthly grant or reset job that applies those constants to accounts. New profile balances default to zero in the database schema. Treat the displayed monthly amounts as configured plan targets, not as verified automatic grants, until grant automation is implemented. The balance shown in the portal and the desktop Settings badge is the amount currently available to spend.

    How additional capacity works today

    The Cloud API has an implemented Stripe backend: it can create a validated Checkout Session for a configured package, and its signed webhook can add the purchased credits to an account.

    That backend is not connected to a self-service purchase control in the current portal. The portal’s Subscription and Top Up tabs both direct users to contact the Nolain team; the Top Up page explicitly says self-service top-ups are unavailable. Do not expect those tabs to open Stripe Checkout yet.

    What measured queries cost

    The query-cost benchmark measured three 50-question runs on hard retail-invoice questions:

    • GPT-5.6 Luna with Pandas code only averaged 4.08 charged credits per question.
    • DeepSeek V4 Flash 0731 with Pandas code only averaged 2.76.
    • GPT-5.6 Luna with Pandas plus a computation graph averaged 38.84.

    These figures are descriptive measurements, not estimates guaranteed for a new file. They include worker calls but exclude conversation-side classification, semantic reading, and optional answer framing, so an interactive turn can cost more. The runs also differed in retry and success rates and had no ground-truth answers. In that sample, enabling the computation graph was the largest visible cost increase.

    For your own recent activity, Settings → Query usage aggregates locally stored token counts and answer times over one day, seven days, or 30 days. Those token charts are usage evidence, not the authoritative account balance; use the credit badge or portal balance for the latter.

    You can now distinguish verified per-call charging, measured query costs, and plan amounts that are not yet automatically granted. See Troubleshooting for a zero-credit response, or continue with How Nolain is built to understand why planning is remote while execution stays local.
