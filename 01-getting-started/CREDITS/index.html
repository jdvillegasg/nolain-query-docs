    Credits

    The last chapter got you to a working query. This one answers a practical question: what does a question cost?

    Credits are prepaid tokens for reasoning work — calls to a language model. They are not a charge for “running your data.” Local execution on your machine is free. You pay for the thinking the cloud does on your behalf.

    Technical charging, ledgers, and HTTP 402 behavior live in Billing internals. This chapter stays on the user side: the unit, the monthly allowance, a worked example, and what is free.

    What a credit is

    1,000 credits = $1 of model usage, or 1 credit = $0.001.

    Two numbers are added together on every model call:

    • Token credits — the model’s actual token cost, converted at that rate and rounded up.
    • Surplus credits — a platform margin, a configurable fraction of token credits. The default is 100%, so the surplus equals the token credits.

    With the default surplus, the amount deducted is roughly twice the raw token cost. Surplus exists so retries, pricing drift, and the cost of running the service are not hidden inside a flat “per question” price.

    Why not charge per question?

    A question is not one call. The cloud may classify your intent, read the wording for ambiguities, generate analysis code, optionally compile a computation graph, optionally write a chart contract, and — if you ask — frame the result as a short narrative. Each of those is a separate model call. A failed compile still used a model. A clarification still used a model.

    Charging per call matches what actually happened. The product is honest that a “simple question” can be several calls, and that a question which never generates code can still cost something if a model was asked to classify it.

    How much you start with each month

    Credits reset on the UTC calendar month. Top-ups you purchase do not expire at month end.

    Plan Credits at the start of each month Approx. dollar value
    Free 1,000 $1
    Premium 50,000 $50
    Top-ups Added when purchased do not expire at month end

    Your balance appears in the desktop Settings panel and on the portal.

    How one model call is priced

    token_credits   = ceil(model_cost_usd × 1000)
surplus_credits = ceil(token_credits × surplus_rate)    # default surplus_rate = 1.0
charged_credits = token_credits + surplus_credits

    Example: a call that cost $0.0026 in tokens becomes 3 token credits (ceil(2.6)). With 100% surplus that is another 3, so 6 credits are deducted.

    Part Meaning
    Token credits Actual model usage (1 credit ≈ $0.001 of tokens), rounded up
    Surplus credits Platform margin as a fraction of token credits (default 100%)

    Every model call is charged as soon as it completes. Failed or cancelled jobs still cost credits for calls already made. Queueing a job, by itself, does not.

    What a full question tends to cost

    The benchmark report ran 50 hard retail questions through the desktop conversation loop. Those totals include every worker model call in the job. They do not include the cheaper conversation-side calls (classification, semantic reading, optional narrative), so a live question can cost a little more than the figures below.

    Setup Average credits per question
    GPT-5.6 Luna, analysis code only 4.08
    DeepSeek V4 Flash, analysis code only 2.76
    GPT-5.6 Luna, analysis code plus computation graph 38.84

    On the Free plan (1,000 credits/month), those averages imply roughly:

    • ~245 GPT-5.6 Luna analysis-only answers, or
    • ~26 GPT-5.6 Luna answers that also built a graph, or
    • a different amount depending on the model, the question, and retries

    Premium (50,000 credits/month) is 50× the Free allowance. These are measured slices, not a guaranteed number of questions. Turning on the computation graph is the largest cost lever in that sample: the same model went from about 4 credits to about 39.

    A successful job’s running total appears as billing.charged_credits on the job status the desktop polls.

    What is free, and what is not

    Free

    • Replies that never call a model (some metadata answers: column lists, row counts, types)
    • Reading the status of a job that already started

    Not free

    • Any step that invokes a model: classifying the turn, reading the question for ambiguity, generating code, compiling a graph, writing a chart contract, framing a narrative

    Off-topic questions still cost the classification call if a model was used to decide they were off-topic.

    Buying more credits

    Premium plans and top-up packs are sold through Stripe. Purchased credits are added to your balance after payment.
