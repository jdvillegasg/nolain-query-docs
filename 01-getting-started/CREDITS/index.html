    Credits — what you pay and what you get

    This page is for users and customers. Technical billing internals live in BILLING.md.

    How credits work

    • 1,000 credits = $1 of model usage (1 credit = $0.001).
    • Token credits track actual model token consumption at that rate (rounded up).
    • Surplus credits are a configurable fraction of token credits (default 100%).
    • Every LLM call is charged as soon as it completes — intent classification, semantic analysis, code generation, DAG compilation, visualization, synthesis, etc.
    • Failed or cancelled jobs still cost credits for LLM calls already made.

    How much do you start with each month?

    Credits reset on the UTC calendar month.

    Plan Credits at the start of each month Approx. dollar value
    Free 1,000 $1
    Premium 50,000 $50
    Top-ups Added when purchased do not expire at month end

    Your balance appears in the desktop app Settings panel and on the website.

    What one LLM call costs

    token_credits = ceil(model_cost_usd × 1000)
surplus_credits = ceil(token_credits × surplus_rate)    # default surplus_rate = 1.0
charged_credits = token_credits + surplus_credits

    With the default surplus rate of 100%, total cost is roughly 2× token credits (e.g. 3 token credits + 3 surplus = 6 charged).

    Part Meaning
    Token credits Actual model usage (1 credit ≈ $0.001 of tokens), rounded up
    Surplus credits Platform margin as a fraction of token credits (default 100%)

    Observed full-query examples

    The benchmark report contains three 50-query runs. These totals include every worker LLM call, so they are not the price of one individual call:

    • GPT-5.6 Luna, Pandas only: 4.08 credits average.
    • DeepSeek V4 Flash 0731, Pandas only: 2.76 credits average.
    • GPT-5.6 Luna, Pandas plus DAG: 38.84 credits average.

    See the benchmark report for the full method, ranges, retries, and limitations.

    A full successful query often involves multiple LLM calls (intent, semantics, code, optional DAG/chart). Job status shows accumulated billing.charged_credits.

    On the Free plan (1,000 credits/month):

    • ~245 GPT-5.6 Luna Pandas-only answers in the measured run, or
    • ~26 GPT-5.6 Luna Pandas-plus-DAG answers in the measured run, or
    • A different amount depending on the model, question, and retries

    Premium (50,000 credits/month) provides 50× the Free-plan credits. These are rough estimates, not a guaranteed number of questions.

    Other models

    More expensive models produce higher token credits; surplus scales with them. The benchmark report records measured results for specific models and run configurations.

    What is free

    • Off-topic, explanation, and metadata replies that do not call an LLM
    • Reading task status for a job already started

    What is not free

    • Any endpoint or workflow step that invokes an LLM (conversation, generation, analyze_query, synthesis, etc.)

    Buying more credits

    Premium plans and top-up packs are sold through Stripe. Purchased credits add to your balance after payment.
